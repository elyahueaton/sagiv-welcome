# SAGIV EATON – אתר אימון בהרמת משקולות אולימפית

אתר סטטי בעמוד אחד, בעברית (RTL). אין בו build, אין תלויות ואין שרת.

## מבנה

```
index.html        כל ה־HTML, ה־CSS וה־JS בקובץ אחד
images/
  hero-snatch.jpg   תמונת הפתיחה (מוצגת בגווני כחול דרך mix-blend-mode)
  about-smile.jpg   התמונה בחלק "עליי"
  club-120kg.jpg    התמונה בחלק המועדונים
```

פונטים: Karantina (כותרות) ו־IBM Plex Sans Hebrew (טקסט), נטענים מ־Google Fonts.

## חלקי העמוד

פתיחה (hero) עם לוח ניסיון מונפש ← רצועת הישגים ← עליי ← ניתוח טכני חינם (טופס) ← מסלולים ומחירים, כולל באנר "מקומות מייסדים" וטבלת השוואה ← איך מתחילים ← מועדונים (טופס קביעת סדנה) ← שאלות נפוצות ← יצירת קשר.

קטע המלצות מוכן ונמצא בהערה (comment) לפני החלק של המועדונים. כשיש המלצות, מוציאים אותו מההערה וממלאים.

## טפסים ← וואטסאפ

אין backend. כל טופס בונה הודעה מסודרת ושולח אותה ל־`https://wa.me/972587372252?text=...`:

| טופס | איפה | מזהה |
|---|---|---|
| הרשמה למסלול | חלון `<dialog id="signup">`, נפתח מכפתורים עם `data-signup="general|full"` (ועם `data-founder` למקום מייסד) | `#su-form` |
| ניתוח סרטון חינם | בחלק `#free` | `#free-form` |
| קביעת סדנה למועדון | בחלק `#clubs` | `#club-form` |

**חשוב:** כפתור השליחה הוא `<a data-send>` אמיתי, וה־`href` שלו מתעדכן בכל שינוי בטופס. בכוונה לא משתמשים ב־`window.open`, כי הוא נחסם בדפדפן הפנימי של אינסטגרם ובתוך iframes. בטלפון הקישור נפתח באותה לשונית, ובמחשב בלשונית חדשה.

## הגדרות

בתחילת הסקריפט, בתחתית `index.html`:

```js
var CONFIG = {
  phone: '972587372252',
  pay: { general: '', full: '', founder: '' },  // קישורי תשלום (Morning / Grow / PayBox וכו')
  calendar: ''                                   // קישור ליומן קביעת פגישות
};
```

- כשיש קישור ב־`pay`, אחרי ההרשמה מופיע כפתור "לתשלום מאובטח" לפי המסלול שנבחר.
- כשיש קישור ב־`calendar`, בטופס המועדונים מופיע הקישור "ליומן הפנוי שלי".

## אחסון

כרגע ב־Netlify (Drop). לעדכון גוררים את התיקייה כולה, עם `index.html` ותיקיית `images`, ל־Deploys.
